# Download the brand fonts

Font binaries are not bundled here. Install these open-source families from their official sources:

- **Inter Display / Inter** — https://github.com/rsms/inter — SIL Open Font License 1.1
- **PT Mono** — https://fonts.google.com/specimen/PT+Mono — SIL Open Font License 1.1

Recommended files/weights:

- Inter Display SemiBold, Bold, ExtraBold
- Inter Regular, Medium, SemiBold, Bold
- PT Mono Regular and Bold

The logo wordmarks are already converted to vector outlines, so the logo SVGs do not require the fonts to be installed.
