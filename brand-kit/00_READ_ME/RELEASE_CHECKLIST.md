# Release checklist

- [ ] Correct primary or secondary signature selected
- [ ] Minimum size and clear space respected
- [ ] Only approved color tokens used
- [ ] Typography uses Inter Display / Inter / PT Mono roles
- [ ] Icons follow the 24x24 / 1.75-square-stroke system
- [ ] Copy is concrete, evidence-led, and free of inflated claims
- [ ] Contrast and keyboard focus pass accessibility review
- [ ] Third-party license notices retained

## Writing

See `../08_WRITING/WRITING_STYLE.md` for the full spec.

- [ ] Register picked on purpose and held all the way through
- [ ] Every heading, title, nav item, and button label is lowercase
- [ ] Opens on something concrete — scene, object, number, blunt claim, or real question
- [ ] Sentence lengths vary; at least one fragment or sub-six-word sentence doing real work
- [ ] Semicolons, ellipses, or a parenthetical aside present and used properly
- [ ] Em dashes counted — fewer than one per two hundred words
- [ ] Every oversized word is a joke or genuinely the precise one
- [ ] Specifics and numbers where adjectives were tempting
- [ ] Ends on a deflation, an admission, or a loose end — not a call to action
- [ ] Checked against `../08_WRITING/AI_TELLS.md`; none of it survived
