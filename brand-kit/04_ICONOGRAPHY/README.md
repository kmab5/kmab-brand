# Iconography

This package includes a custom 24-icon core set drawn on a 24x24 grid with a 1.75-unit square-capped stroke. Use the supplied SVGs for the common portfolio and product actions.

For additional icons, use **Lucide** as the extension library and normalize it to the same 24x24 grid, 1.75 stroke, square caps, and square joins. Lucide is open source under the ISC License: https://lucide.dev/

Rules:

- Use icons to clarify actions, not decorate headings.
- Pair unfamiliar icons with labels.
- Default sizes: 16, 20, 24, 32.
- Use purple for active/current states; green for validated/success; amber for exploratory/non-critical states.
- Do not mix filled and outlined icons in the same control group.
